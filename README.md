# RM Landing Page - React + TypeScript

Una landing page moderna construida con React, TypeScript y Vite. Este proyecto está pensado para servir como base para una página de presentación, marca, producto o servicio con una estructura limpia, responsiva y fácil de escalar.

## Descripción

Este proyecto utiliza la stack actual de Vite con React y TypeScript para crear una interfaz ligera, moderna y mantenible. Está orientado a proyectos de marketing digital, páginas corporativas, portales de producto o landing pages con secciones de presentación, beneficios, CTA y contacto.

La idea principal es tener una base preparada para:
- Diseñar una landing page visualmente atractiva
- Gestionar componentes reutilizables
- Escalar fácilmente nuevas secciones
- Trabajar con TypeScript para mayor seguridad en el código
- Desplegar rápido con Vite

## Stack Tecnológico

- React
- TypeScript
- Vite
- CSS moderno
- Node.js + npm

## Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- Node.js 18 o superior
- npm o pnpm

## Instalación

```bash
npm install
```

## Ejecución en modo desarrollo

```bash
npm run dev
```

Esto levantará el proyecto localmente y podrás verlo en tu navegador.

## Build de producción

```bash
npm run build
```

Esto genera la versión compilada para producción en la carpeta `dist`.

## Vista previa de producción

```bash
npm run preview
```

## Funcionalidades esperadas

Aunque cada implementación puede variar según el diseño, este tipo de proyecto suele incluir:

- Hero section con título principal y CTA
- Sección de catalogo
- Bloque informativo
- Botones en la navegacion
- Diseño responsive para móvil, tablet y escritorio

## Personalización

Puedes modificar fácilmente:
- textos
- colores
- tipografías
- secciones
- layout
- componentes de React

La estructura modular de React permite crear secciones como:
- Header
- Hero
- catalog
- Footer
